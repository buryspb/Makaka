# Makakalang — просто, как Basic

**Makakalang** — язык для первых программ. Команды пишутся обычными русскими словами. Скобки, двоеточия, запятые и значки сравнения не нужны.

```python
печать "Привет, мир!"
```

Сохрани это в файле `privet.mkk` в кодировке UTF-8, а затем выполни:

```bat
makaka run privet.mkk
```

Готово — ты создал настоящее Windows-приложение.

## Быстрый старт

Нужны 64-разрядная Windows и Python 3.10 или новее. Портативные NASM и GoLink уже лежат в `tools/bin`; ничего устанавливать и настраивать не требуется.

Из корня проекта:

```bat
makaka build examples\hello.mkk
examples\hello.exe

makaka run examples\calculator.mkk
makaka run examples\guess_number.mkk
```

`build` создаёт рядом с `.mkk` файлы `.asm` и `.exe`. `run` собирает программу и сразу запускает её. `check` только проверяет код:

```bat
makaka check privet.mkk
```

Если инструменты были удалены, восстанови их командой:

```bat
python tools\setup_tools.py
```

## 1. Разговор с программой

### Напечатать текст

```python
печать "Привет!"
печать "Мне нравится Makaka"
```

### Спросить имя

```python
имя = ввод "Как тебя зовут?"
печать "Привет," имя
```

Слова после `печать` разделяются пробелом автоматически. Запятые можно не писать.

### Спросить число

`ввод` получает строку. `число` превращает её в целое число:

```python
возраст = число ввод "Сколько тебе лет?"
печать "Твой возраст:" возраст
```

## 2. Простые решения

Сравнения записываются словами:

| Слово | Что означает |
|---|---|
| `равно` | значения одинаковые |
| `не_равно` | значения разные |
| `меньше` | левое число меньше |
| `больше` | левое число больше |
| `не_меньше` | больше или столько же |
| `не_больше` | меньше или столько же |

Например:

```python
возраст = число ввод "Сколько тебе лет?"

если возраст не_меньше 18
    печать "Ты взрослый"
иначе_если возраст не_меньше 5
    печать "Ты уже большой"
иначе
    печать "Ты ещё совсем маленький"
```

Внутри условия каждая строка начинается с четырёх пробелов. Это показывает, какие команды относятся к условию.

Ещё примеры:

```python
если ответ равно "да"
    печать "Здорово!"

если секрет не_равно 7
    печать "Попробуй ещё"

если очки больше 100
    печать "Победа!"
```

## 3. Повторение

`пока` повторяет команды, пока условие истинно:

```python
счёт = 5

пока счёт больше 0
    печать счёт
    счёт = счёт - 1

печать "Пуск!"
```

`прервать` заканчивает цикл раньше времени. `продолжить` сразу начинает следующий круг:

```python
число = 0

пока число меньше 10
    число = число + 1
    если число равно 3
        продолжить
    если число равно 8
        прервать
    печать число
```

## 4. Свои команды — функции

Функция получает значения и возвращает ответ. Имена параметров пишутся через пробел:

```python
функция сложить а б
    вернуть а + б

ответ = сложить 2 3
печать "Два плюс три:" ответ
```

Можно сразу напечатать результат:

```python
печать "Ответ:" сложить 10 20
```

Функции можно вызывать до их объявления. Рекурсия поддерживается. Функция без `вернуть` возвращает `Ничего`.

## 5. Маленькая игра

```python
секрет = 7
ответ = 0

пока ответ не_равно секрет
    ответ = число ввод "Угадай число: "
    если ответ меньше секрет
        печать "Больше!"
    иначе_если ответ больше секрет
        печать "Меньше!"
    иначе
        печать "Ты угадал!"
```

## Значения и вычисления

```python
число = 42
текст = "Привет"
правда = Истина
ложь = Ложь
```

- Целые числа — знаковые 64-битные.
- Строки — UTF-8, в двойных или одинарных кавычках.
- Комментарий начинается с `#` и продолжается до конца строки.
- `+` складывает числа или соединяет строки.
- `-`, `*`, `/`, `%` вычитают, умножают, делят и берут остаток.
- `и`, `или`, `не` — логические операции.

```python
имя = "Алиса"
печать "Привет, " + имя + "!"

если Истина и не Ложь
    печать "Работает"
```

Нулевое число, пустая строка, `Ложь` и `Ничего` считаются ложью. Остальные значения — истиной. Деление целочисленное. Деление на ноль, переполнение и несовместимые типы выдают понятную русскую ошибку.

Пустой блок записывается словом `проход`:

```python
если Истина
    проход
```

## Можно ли использовать старый синтаксис?

Да, прежние программы остаются совместимыми. По желанию разрешены скобки, запятые, двоеточия и символы сравнений:

```python
функция сложить(а, б):
    вернуть а + б

если сложить(2, 3) == 5:
    печать("Старый вариант тоже работает")
```

Но для новых программ проще использовать слова и пробелы.

## Точный приоритет вычислений

От низкого к высокому:

1. `или`;
2. `и`;
3. `не`;
4. словесные сравнения;
5. `+`, `-`;
6. `*`, `/`, `%`;
7. унарные `+`, `-`;
8. вызовы и необязательные скобки.

В вызове без скобок каждый аргумент — один простой операнд. Поэтому `сложить 2 3 равно 5` означает «результат вызова равен пяти». Для сложного аргумента можно использовать необязательные скобки: `сложить (а + 1) б`.

## Справка по инструментам

Исполняемые файлы используют только системную `kernel32.dll`. При запуске они автоматически вызывают `SetConsoleOutputCP(65001)` и `SetConsoleCP(65001)`, поэтому русский текст работает без `chcp`.

Структура проекта:

```text
compiler/       лексер, парсер, AST, анализ и генератор NASM
examples/       простые готовые программы
makaka.py       интерфейс командной строки
makaka.bat      запуск из cmd.exe
tools/bin/      портативные NASM и GoLink
tests/          автоматические тесты
```

Запуск тестов:

```bat
python -m unittest discover -s tests -v
```

Ограничение MVP: память динамических строк освобождается операционной системой при завершении процесса.
